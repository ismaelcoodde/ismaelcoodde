## 👨‍💻 Sobre mí

Soy desarrollador autodidacta de Palma de Mallorca, España. Mi trayectoria comenzó con el desarrollo web y actualmente también trabajo en **aplicaciones móviles multiplataforma** y sistemas backend.

Me interesa especialmente diseñar productos completos: interfaces intuitivas, APIs bien estructuradas, autenticación, persistencia de datos, lógica de negocio y servicios desplegados en servidores.

- 📱 **Desarrollo móvil:** React Native, Expo, Expo Router y TypeScript.
- 🌐 **Frontend web:** React, Vite, JavaScript, HTML, CSS y Tailwind CSS.
- ⚙️ **Backend y APIs:** Python, FastAPI, Flask, APIs REST y validación de datos con Pydantic.
- 🗃️ **Datos:** PostgreSQL, SQLite, SQLAlchemy, Alembic y Supabase.
- 🔐 **Autenticación y seguridad:** gestión de sesiones, tokens, control de acceso y tratamiento cuidadoso de datos.
- 🚀 **Infraestructura y despliegue:** Git, GitHub, Docker, Coolify y servidores Hetzner.
- 🧪 **Calidad del código:** pruebas de backend, comprobación de tipos y mantenimiento de proyectos.
